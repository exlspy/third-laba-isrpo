# Описание кода

## Файл src/scanner.ts

Типы:
- `VarKind` — возможные типы переменной: `list`, `matrix`, `dict`, `set`, `tuple`, `str`, `int`, `range`, `unknown`.
- `Variable` — найденная переменная: имя, тип и номер строки.

1. `kindTitle(kind)`
- возвращает русское название типа для показа в списке
- входные данные: тип переменной
- выходные данные: строка, например `словарь`

2. `kindByAnnotation(annotation)` (внутренняя)
- определяет тип по аннотации вида `x: list[int] = ...`
- входные данные: текст аннотации
- выходные данные: тип или `undefined`, если аннотация незнакомая

3. `kindByValue(value)` (внутренняя)
- определяет тип по значению справа от `=`: по первому символу (`[`, `{`, `(`, кавычка, цифра), по имени вызываемой функции (`list(`, `dict(`, `range(`, `len(`, `input(` ...) и по окончанию (`.split()`, `.keys()`)
- входные данные: текст значения
- выходные данные: тип, при неудаче `unknown`

4. `findVariables(lines, beforeLine)`
- проходит строки файла до указанной и собирает присваивания в `Map`, чтобы для каждого имени осталось последнее присваивание
- входные данные: массив строк файла, номер строки курсора
- выходные данные: массив переменных, отсортированный от ближайшей к курсору
- пример:
```ts
findVariables(['a = [1, 2]', 'b = "hi"'], 2)
// [{ name: 'b', kind: 'str', line: 1 }, { name: 'a', kind: 'list', line: 0 }]
```

5. `usedNames(lines)`
- собирает все идентификаторы файла в `Set`
- входные данные: массив строк файла
- выходные данные: множество имён

## Файл src/names.ts

1. `singular(name)`
- переводит имя коллекции в единственное число: сначала смотрит в словарь исключений, потом применяет правила окончаний (`ies` -> `y`, `ches/shes/xes/ses` -> без `es`, `s` -> без `s`)
- входные данные: имя коллекции
- выходные данные: имя в единственном числе или то же имя, если правило не подошло
- пример:
```ts
singular('names')     // 'name'
singular('cities')    // 'city'
singular('boxes')     // 'box'
singular('matrix')    // 'row'
singular('class')     // 'class'
```

2. `uniqueName(base, used)`
- возвращает имя, которого ещё нет в множестве занятых и которое не является ключевым словом Python; при совпадении добавляет номер (`item`, `item2`, `item3`), найденное имя добавляется в множество
- входные данные: желаемое имя, множество занятых имён
- выходные данные: свободное имя

3. `itemName(collection, used, fallback)`
- подбирает имя переменной цикла по имени коллекции; если единственное число совпало с исходным именем, берётся запасное имя
- входные данные: имя коллекции, множество занятых имён, запасное имя
- выходные данные: свободное имя
- пример:
```ts
itemName('numbers', new Set(), 'item')             // 'number'
itemName('numbers', new Set(['number']), 'item')   // 'number2'
itemName('data', new Set(), 'item')                // 'item'
```

## Файл src/builder.ts

Типы:
- `LoopVariant` — вариант цикла: идентификатор и подпись для списка выбора.
- `LoopLine` — строка заголовка цикла и её глубина вложенности.
- `LoopRequest` — что нужно сгенерировать: выражение, тип, вариант, занятые имена.
- `RangeResult` — результат разбора границ `range`: выражение либо текст ошибки.

1. `variantsFor(kind)`
- отдаёт список вариантов цикла для типа переменной из таблицы `variants`
- входные данные: тип переменной
- выходные данные: массив вариантов

2. `buildLoop(request)`
- собирает строки заголовка цикла для выбранного варианта: подбирает имена переменных через `itemName`/`uniqueName`, для вложенных вариантов добавляет вторую строку с глубиной 1
- входные данные: запрос `LoopRequest`
- выходные данные: массив `LoopLine`
- пример:
```ts
buildLoop({ collection: 'prices', kind: 'dict', variant: 'items', used: new Set() })
// [{ depth: 0, text: 'for key, value in prices.items():' }]

buildLoop({ collection: 'matrix', kind: 'matrix', variant: 'nested', used: new Set() })
// [{ depth: 0, text: 'for row in matrix:' }, { depth: 1, text: 'for item in row:' }]
```

3. `parseRange(input)`
- разбирает введённые границы `range` через запятую, проверяет количество значений, нулевой шаг и пустой диапазон (только если все значения числовые), убирает лишние аргументы
- входные данные: строка из поля ввода
- выходные данные: `{ expression }` или `{ error }`
- пример:
```ts
parseRange('10')         // { expression: 'range(10)' }
parseRange('0, 10, 1')   // { expression: 'range(10)' }
parseRange('1, n, 2')    // { expression: 'range(1, n, 2)' }
parseRange('5, 5')       // { error: 'С такими границами цикл не выполнится ни разу' }
parseRange('1, 2, 0')    // { error: 'Шаг не может быть равен нулю' }
```

## Файл src/extension.ts

1. `pythonEditor()`
- возвращает активный редактор, если открыт Python-файл, иначе показывает предупреждение
- выходные данные: редактор или `undefined`

2. `documentLines(document)`
- разбивает текст документа на строки
- входные данные: документ VS Code
- выходные данные: массив строк

3. `indentOf(text)`
- возвращает ведущие пробелы строки
- входные данные: строка
- выходные данные: отступ

4. `indentUnit(editor)`
- возвращает один уровень отступа по настройкам редактора: табуляцию или нужное число пробелов
- входные данные: редактор
- выходные данные: строка-отступ

5. `indentForNewLine(lines, lineNumber, unit)`
- считает отступ для вставляемого цикла: ищет вверх первую непустую строку, берёт её отступ и добавляет уровень, если она заканчивается двоеточием
- входные данные: строки файла, номер строки курсора, единица отступа
- выходные данные: отступ

6. `render(loop, base, unit)`
- превращает `LoopLine[]` в готовые строки текста с отступами
- входные данные: строки цикла, базовый отступ, единица отступа
- выходные данные: массив строк

7. `chooseTarget(lines, cursorLine)`
- показывает список переменных и дополнительные пункты (`range(...)`, ручной ввод), при необходимости открывает поле ввода с проверкой через `parseRange`
- входные данные: строки файла, номер строки курсора
- выходные данные: выражение и тип или `undefined`, если выбор отменён

8. `chooseVariant(kind)`
- показывает список вариантов цикла; если вариант один, выбирает его сразу
- входные данные: тип переменной
- выходные данные: идентификатор варианта или `undefined`

9. `insertLoop()`
- обработчик команды «Вставить цикл for»: собирает все шаги вместе, вставляет цикл в пустую строку или после текущей и переносит курсор в тело цикла

10. `wrapSelection()`
- обработчик команды «Обернуть выделенное в цикл for»: определяет выделенные строки, минимальный отступ среди них, сдвигает строки внутрь цикла и заменяет выделение

11. `activate(context)`
- точка входа плагина, регистрирует обе команды

12. `deactivate()`
- вызывается при выключении плагина, ничего не делает
