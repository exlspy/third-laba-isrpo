# Техническое задание

## Цель

Сделать плагин для VS Code, который избавляет от ручного написания заголовков циклов `for` в Python и сам подбирает подходящий вид цикла под данные.

## Требования

1. Плагин работает только в файлах с языком Python. В других файлах команды показывают предупреждение.
2. Плагин добавляет в VS Code две команды:
   - вставить цикл `for` в позицию курсора;
   - обернуть выделенные строки в цикл `for`.
3. Команды доступны через палитру команд, горячие клавиши (`Ctrl+Alt+F`, `Ctrl+Alt+W`) и контекстное меню редактора.
4. Перед вставкой плагин находит переменные, объявленные в файле выше курсора, и показывает их списком с определённым типом. Последние объявленные переменные идут первыми.
5. Тип переменной определяется по аннотации (`x: list[int]`) или по значению справа от `=`: список, список списков, словарь, множество, кортеж, строка, число, `range`. Если определить не удалось, тип считается неизвестным.
6. Для каждого типа предлагается свой набор вариантов цикла (например, для словаря — по ключам, по значениям, по парам).
7. Кроме переменных можно выбрать цикл по `range` с ручным вводом границ. Ввод проверяется: от 1 до 3 значений, шаг не ноль, диапазон не пустой. Лишние значения убираются (`range(0, n, 1)` превращается в `range(n)`).
8. Можно ввести произвольное выражение вручную.
9. Имя переменной цикла подбирается по имени коллекции (единственное число) и не должно совпадать с именами, которые уже используются в файле, и с ключевыми словами Python.
10. Отступ цикла рассчитывается по текущему контексту: если предыдущая строка заканчивается двоеточием, цикл вставляется на уровень глубже. Учитываются настройки редактора (табы или пробелы, размер отступа).
11. После вставки курсор ставится внутрь тела цикла.
12. При оборачивании выделения строки сдвигаются внутрь цикла с сохранением относительных отступов, пустые строки не трогаются.
