# Архитектура плагина

## Как VS Code подключает плагины

VS Code состоит из основного окна (интерфейс, редактор) и отдельного процесса
Extension Host, в котором запускаются все расширения. Расширение — это обычный
npm-пакет с файлом `package.json`, где в разделе `contributes` описано, что
расширение добавляет в редактор (команды, горячие клавиши, пункты меню), а в поле
`main` указан JS-файл с функцией `activate`.

Когда пользователь вызывает команду расширения, VS Code загружает этот файл,
вызывает `activate`, и расширение регистрирует обработчики команд. Дальше
расширение общается с редактором только через API из модуля `vscode`:
читает текст документа, показывает списки выбора и поля ввода, вставляет текст.

## Из чего состоит плагин

Исходники лежат в папке `src` и собираются TypeScript-компилятором в папку `out`.

| Файл | За что отвечает |
|---|---|
| `package.json` | манифест плагина: команды, горячие клавиши, меню, точка входа |
| `src/extension.ts` | точка входа; регистрирует команды, общается с редактором, считает отступы и вставляет текст |
| `src/scanner.ts` | ищет в тексте файла переменные и определяет их тип |
| `src/builder.ts` | хранит варианты циклов для каждого типа и собирает строки цикла |
| `src/names.ts` | подбирает имя переменной цикла и следит, чтобы оно не повторялось |

Модули `scanner`, `builder` и `names` не зависят от VS Code, поэтому их можно
проверить обычным скриптом на Node.js.

## Как работает команда «Вставить цикл for»

1. `extension.ts` берёт активный редактор и проверяет, что это Python-файл.
2. Текст файла разбивается на строки и передаётся в `scanner.findVariables`.
   Сканер проходит строки до курсора, регулярным выражением находит присваивания
   `имя = значение` и складывает их в `Map`, где ключ — имя переменной. Если
   переменная присваивается несколько раз, остаётся последнее присваивание.
   Тип определяется по аннотации или по началу значения.
3. Найденные переменные показываются в `QuickPick`. Дополнительно есть пункты
   `range(...)` и «Другое выражение».
4. Для выбранного типа из `builder.variantsFor` берётся список вариантов цикла
   и показывается вторым `QuickPick`.
5. `scanner.usedNames` собирает `Set` всех идентификаторов файла. Этот набор
   передаётся в `builder.buildLoop`, который через `names.itemName` и
   `names.uniqueName` подбирает имена переменных цикла, а потом собирает
   строки заголовка. Для вложенных циклов строк две, у второй глубина 1.
6. `extension.ts` считает базовый отступ: идёт вверх от курсора до первой
   непустой строки, берёт её отступ и добавляет ещё один уровень, если строка
   заканчивается двоеточием. Единица отступа берётся из настроек редактора.
7. Строки цикла вставляются в документ, курсор переносится в тело цикла.

## Как работает команда «Обернуть выделенное в цикл for»

Шаги 1–5 те же. Дальше берутся выделенные строки, среди непустых находится
минимальный отступ — он становится отступом заголовка цикла. Каждая непустая
строка сдвигается вправо на столько уровней, сколько строк в заголовке цикла
(один для обычного, два для вложенного). Выделение заменяется на заголовок
плюс сдвинутые строки.

## Структуры данных

- `Map<string, Variable>` — найденные переменные, ключ — имя (дубли схлопываются).
- `Set<string>` — занятые имена в файле; пополняется по мере выдачи новых имён.
- `Record<VarKind, LoopVariant[]>` — таблица вариантов циклов по типу переменной.
- `Record<string, string>` — словарь исключений для единственного числа (`people` -> `person`, `matrix` -> `row`).
- `LoopLine[]` — массив строк заголовка с глубиной вложенности.
