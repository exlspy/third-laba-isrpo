# For Generator

Плагин для VS Code, который генерирует циклы `for` в Python-файлах.

**Автор:** Гайзуллина Ангелина, группа M3101 (ису 558759)

## Что делает плагин

Плагин смотрит на переменные, которые объявлены в открытом файле выше курсора,
определяет их тип (список, словарь, строка, число и т.д.) и предлагает
варианты цикла, которые подходят именно этому типу. Имя переменной цикла
подбирается автоматически по имени коллекции (`names` -> `name`,
`numbers` -> `number`, `prices` -> `key, value`) и не пересекается с именами,
которые уже есть в файле.

Возможности:

- команда **For Generator: Вставить цикл for** (`Ctrl+Alt+F`) — вставляет цикл в позицию курсора с правильным отступом;
- команда **For Generator: Обернуть выделенное в цикл for** (`Ctrl+Alt+W`) — оборачивает выделенные строки в цикл и сдвигает их внутрь тела;
- обе команды есть в контекстном меню редактора для Python-файлов;
- поиск переменных в файле и определение их типа по значению или аннотации;
- для списков и кортежей: обычный цикл, `enumerate`, `reversed`, цикл по индексам;
- для списков списков: цикл по строкам, вложенный цикл по элементам, вложенный цикл по индексам `i, j`;
- для словарей: по ключам, по значениям, по парам `items()`;
- для строк: по символам, по символам с индексом, по словам `split()`;
- для чисел: `range(n)` и обратный отсчёт;
- для множеств: обычный цикл и `sorted`;
- цикл по `range` с ручным вводом границ, проверкой ошибок (нулевой шаг, пустой диапазон) и упрощением записи (`range(0, 10, 1)` -> `range(10)`);
- цикл по произвольному выражению, введённому вручную;
- автоматический подбор имени переменной цикла и защита от совпадения с существующими именами;
- учёт настроек редактора (пробелы или табы, размер отступа).

## Установка и запуск

1. Клонировать репозиторий и установить зависимости:

```
npm install
npm run compile
```

2. Открыть папку проекта в VS Code и нажать `F5` — откроется окно с подключённым плагином и папкой `examples`.

Либо собрать пакет и установить его:

```
npx @vscode/vsce package
code --install-extension for-generator-0.1.0.vsix
```

## Использование

1. Открыть любой `.py` файл, поставить курсор на строку, куда нужен цикл.
2. Нажать `Ctrl+Alt+F` или выбрать команду в контекстном меню.
3. Выбрать переменную из списка (или `range(...)`, или ввести выражение вручную).
4. Выбрать вид цикла.

Пример: в файле есть `prices = {"хлеб": 40, "молоко": 90}`, выбираем `prices` и «по парам ключ-значение» — плагин вставит

```python
for key, value in prices.items():
    
```

и поставит курсор в тело цикла.
